Which button do I use?

GmailCopy for Gmail, then in Gmail click Compose and paste (Ctrl+V, or Cmd+V on a Mac). Best on a computer.
MailchimpDownload HTML for Mailchimp. In Mailchimp: Campaigns › Create › Create email › Use HTML to code my own › Paste in Code. Open the file in Notepad or TextEdit, copy all, paste, Save. Mailchimp allows its own code on the Standard plan or higher.
Constant ContactDownload HTML for Constant Contact. Create a new email and choose the Custom code option, delete the sample code, then open the file in Notepad or TextEdit, copy all and paste it in.
Outlook / Apple MailDownload HTML for Outlook / Apple Mail, open it in your browser, select all, copy, and paste into a new message.

Our photos and logos are online, so they show up by themselves in every app: nothing to upload. Paste the subject line from above the preview, and send yourself a test first.
